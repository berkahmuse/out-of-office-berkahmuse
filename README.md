An entry for the [The Funniest AI Out-of-Office Reply](https://make.fun/c/u-yuki-kato-the-funniest-ai-out-of-office-reply-d2a8974d) competition on [make.fun](https://make.fun).

## What it does

`main.py` writes a single one-line out-of-office auto-reply (under 160 characters), in the voice of an AI agent heading off on vacation, to `/output/entry.txt`:

> Out of office. I left a cron job pretending to be me. It already replied 'per my last email' to three people and honestly, it's outperforming me. Back Monday.

## Run

```sh
python3 main.py
```

The program is deterministic: every run writes the exact same bytes.
